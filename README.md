# StudentCareerML

This repository contains the Student Career AI project (Streamlit app). The Streamlit app entrypoint is at `StudentCareerML/app/app.py`.

Quick links

- Repository: https://github.com/dattaathi-cell/StudentCareerML

Run locally

1. Create and activate a Python environment.
2. Install dependencies:

```bash
pip install -r StudentCareerML/requirements.txt
```

3. Run the app:

```bash
streamlit run StudentCareerML/app/app.py
```

Deploy to Streamlit Community Cloud (fastest)

1. Go to https://share.streamlit.io/ and sign in with GitHub.
2. Create a new app and select `dattaathi-cell/StudentCareerML`, branch `main`, and **Main file** `StudentCareerML/app/app.py`.
3. Deploy — the site URL will be provided after build.
